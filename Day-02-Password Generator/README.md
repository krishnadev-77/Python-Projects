# 🔐 Password Generator

A simple Python program that generates random passwords based on the length entered by the user.

## 🎯 Features

- Generates random passwords
- User can choose the password length
- Includes:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Validates password length
- Allows generating multiple passwords
- Includes a yes/no option to continue

## 🛠️ Technologies Used

- Python
- Random module
- String module

## ▶️ How to Run

Run the following command in the terminal:

```bash
python main.py
