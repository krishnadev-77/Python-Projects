# 💰 Python Expense Tracker with JSON

A command-line Expense Tracker built with Python that allows users to add, view, calculate, delete, save, and load expenses.

This version improves the basic Expense Tracker by using **JSON file storage**, allowing expenses to be saved and loaded even after the program is closed.

## 🚀 Features

- Add expenses
- View all expenses
- Calculate total expenses
- Delete expenses
- Save expenses to a JSON file
- Load expenses from a JSON file
- Basic invalid input handling
- Menu-driven command-line interface

## 🛠️ Technologies Used

- Python 
- JSON
- Lists
- Dictionaries
- Loops
- Conditional statements
- Functions
- File Handling
- `json.dump()`
- `json.load()`
- `enumerate()`
