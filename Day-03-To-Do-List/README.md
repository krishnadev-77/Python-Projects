# 📝 Python To-Do List

A simple command-line To-Do List application built with Python.

## 🚀 Features

- Add tasks
- View tasks
- Complete tasks
- Delete tasks
- Exit the application

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run:

```bash
python main.py
